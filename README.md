## 📷 Screenshot Scanner (Experimental)

> *"Work in progress – I hate it, but I want it!"*

The tool includes a 100% client-side OCR scanner (runs entirely in your browser without external servers or API limits). It automatically detects your units and levels from screenshots.

### 💡 Tips for the Best Scan Results:
* **UI Size:** In Roblox ingame Settings, set `UI Size` to **Medium** or **Large** for the most accurate level detection.
* **Large Inventories:** If you have more Buildings/Pets than fit on one screen, simply scroll down in-game, paste the second screenshot, and apply it.
* **Review:** If a level is blurry, the scanner safely defaults to `Lvl 1` with a `Hard to read` note. Just tap the dropdown to adjust it before applying!
